# Shapefiles

County boundary files used in this analysis are from the **U.S. Census Bureau TIGER/Line** program and are in the **public domain**.

## Download

```bash
# 2020 county cartographic boundary file (500k resolution)
wget https://www2.census.gov/geo/tiger/GENZ2020/shp/cb_2020_us_county_500k.zip
unzip cb_2020_us_county_500k.zip -d ./
```

Direct link: https://www2.census.gov/geo/tiger/GENZ2020/shp/cb_2020_us_county_500k.zip

## Files expected

After unzipping, place the following files in this directory:

```
cb_2020_us_county_500k.cpg
cb_2020_us_county_500k.dbf
cb_2020_us_county_500k.prj
cb_2020_us_county_500k.shp
cb_2020_us_county_500k.shx
```

## Citation

U.S. Census Bureau (2020). TIGER/Line Shapefiles: Counties and Equivalent Areas.
Retrieved from https://www.census.gov/geographies/mapping-files/time-series/geo/tiger-line-file.html
Public domain.
